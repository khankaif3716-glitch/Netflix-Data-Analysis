# Netflix-Data-Analysis
A Python-based Netflix Data Analysis project using Pandas and Matplotlib to explore Netflix movies and TV shows, analyze content ratings, movie durations, release years, and country-wise content distribution through data visualization.

Project OverView:
-> This project focuses on the Analysis Netflix Movies and TV Shows using Python. It's uses 
Pandas for Data Cleaning and Manipulation and The Matplotlib for Data Visualization.

Technical Tools:
.Python
.Pandas
.Matplotlib
.Jupyter Notebook / VS Cod
